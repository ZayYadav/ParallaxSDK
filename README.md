# ParallaxCore

ParallaxCore is the SDK-only distribution. Loader applications, web panels and unrelated projects are intentionally excluded.

Build: `./gradlew :ParallaxCore:assembleRelease`

Release AAR: `ParallaxCore/build/outputs/aar/ParallaxCore-release.aar`

Existing compatible backend/trust endpoints are preserved where runtime compatibility requires them; SDK/module/class/native branding is ParallaxCore.
